# 02 — Directrices UI/UX

## Objetivo

Guiar el diseño visual del Frontend (shadcn/ui + Tailwind).

## Alcance

- Login, shell, admin usuarios/perfiles e indicadores futuros

## Principios

1. Visual primero: jerarquía, espaciado, UX
2. Paleta: primary teal/emerald; estados emerald / amber / rose
3. Bordes redondeados (`rounded-xl` / `rounded-2xl`), sombras suaves, transiciones
4. Tailwind refinado; layout tipo desktop-dashboard
5. Priorizar componentes UI sobre backend salvo petición explícita
